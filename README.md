# A-PILCat

白毛、猫耳、圆眼镜、粉旗袍的 Q 版表情包一套，共 **111 张 / 88 条不同文案**。
透明背景，已按表情文案命名，可直接拖进微信 / QQ / Telegram / Discord。

## 目录结构

```
A-PILCat/
├── png/    # 111 张透明 PNG，最长边 512
├── webp/   # 111 张 WebP（同尺寸，q90），体积约为 PNG 的 1/4
├── 清单.csv # 文件名 <-> 表情文案 <-> 原文件名
└── README.md
```

## 规格

| 项目 | 值 |
|---|---|
| 数量 | 111 |
| 最长边 | 512 px（保持原始宽高比，不裁切、不拉伸、不补方） |
| 常见尺寸 | 489x512 ×6, 491x512 ×5, 487x512 ×4, 492x512 ×4, 512x509 ×3 |
| 透明 | 有（PNG / WebP 均为真 alpha，非白底抠图） |
| 体积 | png 32.7 MB · webp 8.1 MB |

## 命名规则

- 文件名 = 图上的表情文案，去掉标点和空格，如 `冷漠.png`、`只准想我.png`。
- 同一文案出现多次时按 `_2`、`_3` 编号，如 `赢了.png` / `赢了_2.png` / `赢了_3.png`。
- `啊？` 归一为 `啊`。

## 关于原图

原图为 2048x2048，含右下角平台角标。本仓库里的版本已移除角标、把白底转成透明通道，
并按表情文案重新命名。透明处理用形态学闭运算封闭线稿断口后从边框洪水填充，
因此头发、脸部、旗袍等被描边围住的白色区域会保留为不透明。
如需高清二次编辑版本，issue 里说一声。
