# A-PILCat

白毛、猫耳、圆眼镜、粉旗袍的 Q 版表情包一套，共 **250 张 / 228 条不同文案**。
透明背景，已按表情文案命名，可直接拖进微信 / QQ / Telegram / Discord。

## 目录结构

```
A-PILCat/
├── png/                      # 250 张透明 PNG，最长边 512
├── webp/                     # 250 张 WebP（同尺寸，q90），体积约为 PNG 的 1/4
├── 清单.csv                   # 文件名 <-> 表情文案 <-> 原文件名
│
├── scripts/                  # ★ 生成管线全部代码（含被否决的实验，完整留痕）
├── assets/
│   ├── source-native/        # ★ 155 张原生高清源图（1700~2000px 白底原图）
│   ├── deliver/              # ★ 终版三件套：3 帧 GIF 动画 + 缩略图 + 封面，10 组
│   ├── box300/               # 上一代 300x300 BOX 降采样三件套，11 组
│   └── redraw-candidates/    # 1024px SD 重绘候选 462 张（每贴纸 3 张，按包分目录）
├── preview/
│   ├── deliver/              # 从 zip 导出的 GIF，网页可直接看动画
│   └── box300/
└── README.md
```

带 ★ 的是生成管线相关的新增内容，详见 [scripts/README.md](scripts/README.md)。

## 命名规则

- 文件名 = 图上的表情文案，去掉标点和空格，如 `冷漠.png`、`只准想我.png`。
- 同一文案出现多次时按 `_2`、`_3` 编号，如 `赢了.png` / `赢了_2.png` / `赢了_3.png`。
- `啊？` 归一为 `啊`。

## 关于原图

原图为 2048 级高清图，早期一批含右下角平台角标。本仓库里的版本已移除角标、把白底转成透明通道，
并按表情文案重新命名。

这批表情在角色外轮廓上有一圈很淡的模切描边（约 235-248 灰），而头发内部与远背景同为 252 纯白，
部分发梢甚至没有描线。所以透明化不是简单地"把白色去掉"——那样会从描线断口处倒灌进头发，
把整头白发挖空。做法是从边框出发只填充与背景同色的像素，遇到这圈模切描边即停止，
再对线稿做形态学闭运算补住断口，因此头发、脸部、旗袍等被围住的白色区域全部保留为不透明。

全尺寸白底原图已收录在 `assets/source-native/`（155 张，用于下述生成管线）。

## 动画表情包（生成管线产出）

在静态图之上，用 **SD1.5 + ControlNet lineart_anime img2img 真重绘**为每张贴纸画了 3 张候选，
再组成 3 帧 GIF，按平台规范打包成三件套：

| 产物 | 规格 |
|---|---|
| `表情动画.zip` | 300x300 GIF ×16，3 帧重绘，白色 3px 描边、透明底、第一帧完整，单张 ≤250KB |
| `表情缩略图.zip` | 300x300 PNG ×16（取第 1 帧），≤200KB，与 GIF 命名一一对应 |
| `表情封面图.png` | 200x200，无文字、不切头，≤100KB |

- `assets/deliver/` —— 终版（10 组：第01~09包 + 剩余10张）
- `assets/box300/` —— 上一代 BOX 降采样版（含 Example 精选包）
- `assets/redraw-candidates/` —— 重绘的 1024px 原始候选（每贴纸 3 张，可事后换帧）
- `preview/` —— 从 zip 导出的 GIF，方便在网页直接看动画

> 平台对 GIF 关键词有 ≤4 字符限制，`打call` / `DNA动了` 在 GIF 包内对应改为
> `应援` / `心动了`（仅文件名，画面与 `png/` 里的原图一一对应）。

生成代码、逐条提示词表（154 条）、A/B 调参证据与踩坑记录都在 `scripts/`。
