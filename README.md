# A-PILCat

白毛、猫耳、圆眼镜、粉旗袍的 Q 版表情包一套，共 **240 张 / 218 条不同文案**。
透明背景，已按表情文案命名，可直接拖进微信 / QQ / Telegram / Discord。

## 目录结构

```
A-PILCat/
├── png/    # 240 张透明 PNG，最长边 512
├── webp/   # 240 张 WebP（同尺寸，q90），体积约为 PNG 的 1/4
├── 清单.csv # 文件名 <-> 表情文案 <-> 原文件名
└── README.md
```

## 规格

| 项目 | 值 |
|---|---|
| 数量 | 240 |
| 最长边 | 512 px（保持原始宽高比，不裁切、不拉伸、不补方） |
| 常见尺寸 | 1904x1753 ×3, 1681x1728 ×3, 1665x1931 ×2, 1665x1737 ×2, 1665x1752 ×2 |
| 透明 | 有（PNG / WebP 均为真 alpha，非白底抠图） |
| 体积 | png 72.4 MB · webp 18.7 MB |

## 命名规则

- 文件名 = 图上的表情文案，去掉标点和空格，如 `冷漠.png`、`只准想我.png`。
- 同一文案出现多次时按 `_2`、`_3` 编号，如 `赢了.png` / `赢了_2.png` / `赢了_3.png`。
- `啊？` 归一为 `啊`。

## 关于原图

原图为 2048 级高清图，早期一批含右下角平台角标。本仓库里的版本已移除角标、把白底转成透明通道，
并按表情文案重新命名。

这批表情在角色外轮廓上有一圈很淡的模切描边（约 235-248 灰），而头发内部与远背景同为 252 纯白，
部分发梢甚至没有描线。所以透明化不是简单地"把白色去掉"——那样会从描线断口处倒灌进头发，
把整头白发挖空。做法是从边框出发只填充与背景同色的像素，遇到这圈模切描边即停止，
再对线稿做形态学闭运算补住断口，因此头发、脸部、旗袍等被围住的白色区域全部保留为不透明。

需要 2048 原尺寸版本（本地共 606.5 MB）的话在 issue 里说一声。
